# NBA Player Stats Analyzer

A Python program that analyzes NBA player statistics from 1996 to 2020, 
identifying top performers, league averages, and historical trends.

## What it does
- Loads and cleans NBA player stats from a CSV dataset
- Calculates average points, assists, and rebounds per season
- Identifies top and bottom performers in points, assists, and rebounds
- Creates a PRA (Points + Rebounds + Assists) combined stat
- Finds the highest and lowest PRA performers in NBA history

## Key Findings
- **Total players analyzed:** 2,235
- **Top scorer:** James Harden — 36.1 pts
- **Top passer:** Rajon Rondo — 11.7 ast
- **Top rebounder:** Danny Fortson — 16.3 reb
- **Highest PRA:** Russell Westbrook — 53.0
- **Lowest PRA:** Trey McKinney-Jones — 0.0

## Technologies
- Python
- pandas
- zipfile

## Dataset
NBA Players Stats dataset from Kaggle — covers seasons 1996-97 to 2019-20.

pip install pandas
python nba_analyzer.py
